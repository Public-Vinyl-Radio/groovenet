It refuses to overwrite edits made by another process while it is open. Do not run two reviewers or edit the JSON in an editor concurrently. It never displays AI notes or variant rankings.

## Playlist proxy

For each track with playlist mates in the export, measure first-mate MRR and recall@10 of distinct playlist mates among all other tracks, with self-matches excluded. Deduplicate playlist membership; report how many seeds have usable mates, playlist size distribution, tracks with/without notes, and optionally a same-release-excluded slice to expose album leakage. Playlists contain contrasts and purposeful transitions, so this is a noisy proxy, not a definitive relevance label. All variants must use the same track universe, model, similarity formula and exact nearest-neighbour ranking; no serving rows are modified.
