Open **Enrich** to work through tracks with missing metadata. For each track, check the artist, title and recording before choosing an Apple Music or YouTube result. Use the search override if the first query misses.

Edit tags and notes while reviewing the track. Save the match before moving on; skip a track when the result is uncertain. The wizard shows progress and a completion screen.

Downloads and audio analysis are separate jobs. A streaming URL is a match, not a BPM or key measurement. Queue audio after checking the match, then let the download worker and Essentia analyse it. Missing-data filters help you find what still needs work.

Provider credentials belong in the server's [integration settings](/docs/configuration/integrations/).
